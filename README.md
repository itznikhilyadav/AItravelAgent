# ExploreX AI – AI-Powered Travel Planner Agent

An intelligent AI-powered travel planning and recommendation system built using Django, Python, and Large Language Models (LLMs).

## 🌐 Live Demo
[**Click here to explore ExploreX AI**](https://aitravelagent-6jc6.onrender.com/)

## 💻 Source Code

## ✨ Features
- AI-powered destination recommendations
- AI travel chatbot
- Personalized trip itinerary generation
- Weather information
- Travel planning assistance

## 🛠️ Technologies Used
- Python and Django
- Machine Learning and LLMs
- Groq API
- OpenWeather API
- HTML, CSS, and JavaScript
- PostgreSQL / SQLite
